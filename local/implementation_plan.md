# LiteRT-LM 示例程序实施计划

## Context
用户需求：在项目根目录创建local文件夹，深度梳理工程所有示例程序，编写通俗易懂的说明文档（含可视化绘图），分析当前硬件平台适配性，移植可运行示例并编写测试验证，最终提供统一调度脚本一键运行所有示例。

当前环境：
- 系统：Ubuntu 22.04 x86_64
- CPU：Intel i7-14700K (28核)
- GPU：NVIDIA RTX 4070 (12G显存)，CUDA 12.6
- 内存：64G，支持CPU/GPU双后端推理

## 目录结构设计
```
local/
├── README.md                    # 根目录说明文件
├── implementation_plan.md       # 本实施计划文件
├── docs/                      # 文档目录
│   └── examples_guide.md      # 示例程序使用指南
├── examples/                  # 示例实现
│   ├── kotlin/                # Kotlin示例（复用现有代码）
│   ├── cpp/                   # C++示例（新增实现）
│   │   ├── basic_llm_run.cc   # 基础LLM运行示例
│   │   ├── advanced_llm_run.cc # 高级LLM运行示例
│   │   └── BUILD              # 构建配置
│   └── python/                # Python工具（复用现有代码）
├── test/                      # 测试脚本
│   ├── common.sh
│   ├── test_kotlin.sh
│   ├── test_cpp.sh
│   ├── test_python.sh
│   └── test_all.sh
└── run_examples.sh            # 统一调度脚本
```

## 文档实现方案
- 采用markdown格式编写，结构清晰
- 使用mermaid绘制架构图和工作流程图
- 每个示例包含：功能说明、实现原理、核心代码解析、使用方法、运行示例
- 附录包含环境配置、编译指南、常见问题解答

## 测试脚本方案
- 分层设计：通用工具函数 + 各语言测试脚本 + 全量测试入口
- 每个示例包含独立测试用例，验证功能正确性
- 自动生成测试报告，清晰展示测试结果

## 统一调度脚本方案
- 支持命令行参数和交互式菜单两种使用方式
- 功能：环境检测、一键编译、选择运行示例、全量运行
- 自动识别CPU/GPU环境，智能选择最优后端
- 统一日志格式，错误自动捕获和报告
